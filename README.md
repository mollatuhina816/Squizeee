# Squizeee
Quizeee is a real-time live quiz and interactive presentation platform built with Next.js, FastAPI, PostgreSQL, Redis, and WebSockets. It supports role-based access for organization owners, admins, faculty, and students, with features such as live quiz sessions, departments, member management, and real-time answer handling

## Structured question imports

The admin question importer supports independent AI Smart Import and Structured Import (no AI API). See [structured import setup and usage](docs/structured-import.md) for templates, OCR installation, configuration, and validation details.
